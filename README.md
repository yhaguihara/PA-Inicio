# 💻 PA-Inicio — Primeiros Exercícios de Programação

Repositório de atividades introdutórias de Programação e Algoritmos, organizado em listas para acompanhar o aprendizado dos conceitos iniciais de lógica de programação.

## 📖 Sobre o projeto

O **PA-Inicio** reúne exercícios desenvolvidos durante os estudos de programação. As atividades estão divididas em pastas, facilitando a consulta e a organização dos conteúdos praticados.

## ✨ Conteúdo

- 🧠 Exercícios de lógica de programação.
- 📚 Atividades separadas por listas.
- 💻 Prática de conceitos básicos por meio de código-fonte.

## 🛠️ Tecnologias utilizadas

- **Linguagem de programação:** consulte os arquivos de cada lista para identificar a linguagem utilizada.

## 📂 Estrutura do projeto

```text
PA-Inicio/
├── prjLista01/
├── prjLista02/
├── prjLista03/
└── README.md
```

## 🚀 Como executar os exercícios

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/PA-Inicio.git
   ```
2. Entre na pasta:
   ```bash
   cd PA-Inicio
   ```
3. Abra os arquivos de cada lista na IDE ou editor apropriado à linguagem utilizada.

## 🎯 Objetivo de aprendizagem

Desenvolver o raciocínio lógico, praticar os fundamentos de programação e aprender a organizar atividades em projetos separados.
